House model

Wrap any installed model with a permanent AMERB AI persona and instructions, baked in at the Ollama level so it applies no matter what's asked. This does not change the base model's underlying knowledge or weights — it's not fine-tuning, just a fixed system prompt attached to a new model name that shows up in the model picker like any other.

External AI providers

Connect a cloud AI service so staff can choose its models in chat alongside the local ones. Local models keep everything on this machine; an external model sends the staff member's messages, and any knowledge base excerpts used to answer them, to that company's servers, and usage is billed to the API key's account. Staff see a ☁ mark and a notice whenever one is selected. Only enable the models your bank's data policy allows.

Ghana Card numbers, phone numbers, email addresses, TINs and account/card numbers are replaced with placeholders such as [ACCOUNT_NUMBER_1] in everything sent to an external provider — the question, the chat history and any document excerpts — and swapped back for the real values in the reply, so the provider never sees them but staff do. Names and free-text descriptions are not masked.

Tools

AMERB AI can use tools during chat: a sandboxed math/data calculator (always available, no setup needed), a web page fetcher restricted to domains you approve below, an optional web search, and document/image generation. Web search is the one tool that sends user-typed text to an external service (DuckDuckGo) rather than only fetching pre-approved pages, so it's off by default.

Web search

When enabled, the model can call a search tool for current information, then read one of the result pages with the web fetch tool below — even if that page's domain isn't on your approved list.

When on, every search — whether the model calls it or a user forces it with the globe icon — is scoped to only the domains approved below, using DuckDuckGo's own site-restriction. If no domains are approved, search will refuse until you add at least one.

Only the domains approved below are searched — never the open web. Staff see which sites were searched under the reply. Requires at least one approved domain.

Exchange rates

Only the currency pair is sent to the rate service — no customer data, no question text — and the answer always states the rate, the date it was published and where it came from. Off by default. Without it, AMERB AI will not guess a rate.

Point this at the bank's own rate source if it has one. The default is a public service that quotes against the cedi.

When on, new and edited terms stay pending and are not sent to the model until an administrator approves them. Rejecting a term removes it from the AI's vocabulary straight away.

Capability testing

Producing text in a language is not evidence the model can use it, so a language is offered for a model only after it passes these checks: translation accuracy, comprehension, figures kept intact, consistency across two runs, and readable prose instead of repeated nonsense. A run makes several real model calls and takes minutes on a CPU-only machine — progress is shown below, and you can stop it at any time.

Fallback when a model fails

Tried in order, then the global default (—) as a last resort. An answer never switches models halfway through — only when nothing has been written yet. Never add an external model here unless you're happy for a local-model request to fall back to a cloud provider.

    Answer quality by model

    Approval is thumbs up ÷ (up + down). "Confidence" is the statistical lower bound, so a model with one lucky thumbs up doesn't outrank one with ninety out of a hundred. A model is flagged for review below 60% once it has 10 ratings.
