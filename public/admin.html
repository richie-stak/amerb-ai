House model

Wrap any installed model with a permanent AMERB AI persona and instructions, baked in at the Ollama level so it applies no matter what's asked. This does not change the base model's underlying knowledge or weights — it's not fine-tuning, just a fixed system prompt attached to a new model name that shows up in the model picker like any other.

External AI providers

Connect a cloud AI service so staff can choose its models in chat alongside the local ones. Local models keep everything on this machine; an external model sends the staff member's messages, and any knowledge base excerpts used to answer them, to that company's servers, and usage is billed to the API key's account. Staff see a ☁ mark and a notice whenever one is selected. Only enable the models your bank's data policy allows.

Tools

AMERB AI can use tools during chat: a sandboxed math/data calculator (always available, no setup needed), a web page fetcher restricted to domains you approve below, an optional web search, and document/image generation. Web search is the one tool that sends user-typed text to an external service (DuckDuckGo) rather than only fetching pre-approved pages, so it's off by default.

Web search

When enabled, the model can call a search tool for current information, then read one of the result pages with the web fetch tool below — even if that page's domain isn't on your approved list.

When on, every search — whether the model calls it or a user forces it with the globe icon — is scoped to only the domains approved below, using DuckDuckGo's own site-restriction. If no domains are approved, search will refuse until you add at least one.

Audit log

A permanent record of sign-ins (including failed and locked-out attempts), every question asked in chat and which model answered it, document uploads, deletions and sharing, and every admin change. Entries can't be edited or deleted, and they remain after an account or chat is deleted. Passwords and API keys are never recorded. Times are shown in your computer's time zone.

Conversation retention

Automatically delete conversations older than this many days. Runs once a day on its own; 0 means keep everything indefinitely. This cannot be undone — take a backup first if unsure.
