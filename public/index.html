Getting started with AMERB AI

Attach or reference documents

Use the paperclip button to upload a file, or type @ in the message box to reference any document you can see — bank-wide, your department's, or your own files — no re-upload needed.

Voice input

Click the mic button and speak — transcription runs locally on this machine and never leaves it. Click the mic again to stop and drop the text into the message box.

Saved prompts

Workspace menu → Saved prompts. Save anything you type often and reuse it with one click, instead of retyping it each time.

Search all chats

The search icon next to the sidebar's chat filter searches inside every message you've ever sent — not just chat titles.

Regenerate & compare answers

Not happy with a reply? Regenerate it and flip between versions with the arrows underneath. Or open Workspace → Compare models to run the same prompt against two models side by side.

Read replies aloud

Every AMERB AI reply has a speaker icon underneath it — click it to have the answer read aloud.

Custom instructions

Workspace menu → Custom instructions. Tell AMERB AI how you'd like it to respond — it applies to every new message, in every conversation.

Keyboard shortcuts

Ctrl+K new chat · ↑ (empty box) edit your last message · Esc close any open panel or menu.
